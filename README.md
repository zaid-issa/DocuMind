# DocuMind - AI Document Assistant

Upload PDF documents and ask questions about them in natural language.
Answers are grounded in the document and include page-level source citations.

**Status:** in development (Phase 0 - project setup).

## Planned architecture

PDF upload -> text extraction -> chunking -> embeddings -> vector database
-> retrieval -> LLM -> answer with citations.

## Tech stack (planned)

Python, PyMuPDF, ChromaDB, FastAPI, Streamlit, pytest, Docker, GitHub Actions.
